# 작품 관리자 배포 및 사용

관리자 화면 코드는 준비됐지만 배포와 로그인 승인이 필요합니다.

## Cloudflare Pages로 관리자 배포
1. 기존 홈페이지 프로젝트는 그대로 두세요. 별도 Pages 프로젝트를 새로 만들고 동일 GitHub 저장소 n을 연결합니다.
2. 브랜치 main, 루트 디렉터리 studio, 빌드 명령 npm run build, 출력 dist, 환경변수 NODE_VERSION=22.12.0으로 설정합니다.
3. 배포 후 관리자 프로젝트의 https://...pages.dev 주소를 복사합니다.
4. Sanity 프로젝트 API → CORS origins에 관리자 주소를 추가합니다. 관리자 주소에만 Allow credentials를 켭니다. 공개 홈페이지 주소는 끈 상태로 유지합니다.
5. 관리자 주소에서 Sanity 프로젝트를 만든 계정으로 로그인합니다.

## 작품 등록
작품 → 새 문서 → 제목, 사진, 날짜, 구분, 표시 순서 입력 → Publish.
작은 순서 숫자가 먼저 표시됩니다. 영상은 대표 썸네일과 유튜브 HTTPS 주소를 입력합니다.
홈페이지를 새로고침하면 게시된 작품을 불러옵니다. 초안은 노출되지 않습니다.
숨기려면 홈페이지에서 숨기기를 켜고 Publish합니다. 이는 홈페이지에서만 숨기는 기능이며 공개 데이터셋의 자료를 비공개로 바꾸지 않습니다. 민감한 자료는 업로드하지 마세요.
현재 조회는 Sanity의 비캐시 API를 사용하므로 트래픽과 플랜 사용량을 확인하세요.

빌드 및 실제 로그인·게시 테스트는 아직 수행하지 않았습니다. 배포 오류가 나면 로그를 확인하세요.
